# PHEnergyCorrelator

### Authors
Derek Anderson, John Lajoie

### Description
A header-only library to do spin-dependent EEC calculations in
PHENIX analyses. The library aims at being portable and easy
to drop into existing analysis code.

In order to ensure compatibility with the PHENIX software
environment, the library is fully compliant with C++98.

### Dependencies
- ROOT 5.34/36  
- gcc version 4.8.5 20150623
